## Como Executar os Projetos
</div>

Para rodar os códigos localmente, você precisará de um compilador C++ instalado.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JudGB/ProjectsCPP
   ```

2. **Acesse a pasta do projeto desejado:**
   ```bash
   cd ProjectsCPP/Tarefa01_array_Judson_gabriel.cpp
   ```

3. **Compile o arquivo (exemplo através do terminal com G++):**
   ```bash
   g++ nome_do_arquivo.cpp -o programa
   ```

4. **Execute o binário gerado:**
   * **Windows:** `programa.exe`
   * **Linux/macOS:** `./programa`
